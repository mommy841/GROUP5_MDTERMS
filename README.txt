# TechServe University IT Helpdesk — Discrete-Event Simulation

A Python discrete-event simulation (DES) built with **SimPy**, **NumPy**, **Pandas**, and **Matplotlib** to evaluate staffing, AI chatbot deflection, and shift-staggering strategies for a 15-hour daily IT helpdesk operation.

---

## 1. Prerequisites

* **Python 3.8+** (Tested on Python 3.14)
* **Required Libraries:**
  * `simpy` — Discrete-event simulation engine
  * `numpy` — Random number generation and statistical metrics
  * `pandas` — Data aggregation and CSV/Excel reporting
  * `matplotlib` — High-resolution chart generation (requires Matplotlib 3.9+ for `tick_labels` in boxplots)
  * `openpyxl` *(optional)* — Exporting combined results to `.xlsx` Excel format

---
